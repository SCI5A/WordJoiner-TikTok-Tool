# WordJoiner PRO - حامي النصوص العربية

![WordJoiner PRO Logo](icons/icon-192x192.png)

## نظرة عامة

**WordJoiner PRO - حامي النصوص العربية** هي أداة ويب متقدمة مصممة خصيصًا لحل مشكلة دمج الكلمات العربية التي تحدث عند نسخ النصوص ولصقها في تطبيقات التواصل الاجتماعي الشهيرة مثل TikTok، WhatsApp، Telegram، Facebook، و YouTube. تضمن هذه الأداة أن تظل نصوصك العربية منسقة بشكل صحيح ومقروءة دون أي تغييرات غير مرغوبة في بنية الكلمات.

## الميزات الرئيسية

*   **واجهة مستخدم حديثة ومتجاوبة (Responsive UI):** تصميم جذاب وسهل الاستخدام يعمل بسلاسة على جميع الأجهزة، من الهواتف الذكية إلى أجهزة الكمبيوتر المكتبية.
*   **دعم كامل للغة العربية (RTL):** واجهة مصممة خصيصًا لدعم اتجاه النص من اليمين إلى اليسار، مما يوفر تجربة مستخدم طبيعية للمتحدثين باللغة العربية.
*   **الوضع الليلي (Dark Mode):** خيار لتبديل الواجهة إلى الوضع الليلي لتجربة مشاهدة مريحة في ظروف الإضاءة المنخفضة.
*   **خيارات معالجة نص متعددة:**
    *   **Word Joiner (U+2060):** محرف غير مرئي يمنع دمج الكلمات.
    *   **Zero Width Joiner (U+200D):** محرف غير مرئي يربط بين الأحرف.
    *   **Zero Width Non-Joiner (U+200C):** محرف غير مرئي يمنع ربط الأحرف.
    *   **Hair Space (U+200A):** مسافة رفيعة جدًا.
    *   **Thin Space (U+2009):** مسافة رفيعة.
    *   **Non-Breaking Space (U+00A0):** مسافة غير قابلة للكسر.
*   **تجربة تلقائية لأفضل طريقة:** زر ذكي يجرب المحارف المختلفة ويختار الطريقة الأكثر فعالية لضمان أفضل حماية للنص.
*   **أدوات نص متكاملة:** مربع إدخال، مربع للنتائج، أزرار للتحويل، النسخ، المشاركة، المسح، اللصق، واستعادة النص السابق.
*   **دعم النصوص الدينية:** آلية ذكية للحفاظ على الآيات القرآنية، التشكيل، وعلامات الوقف دون تغيير، مع تحذير المستخدم عند معالجة نص قرآني.
*   **إحصائيات النص:** عرض عدد الكلمات، الأحرف، والأحرف قبل وبعد التحويل، بالإضافة إلى حجم النص.
*   **تطبيق ويب تقدمي (PWA) احترافي:** قابل للتثبيت على الشاشة الرئيسية ويعمل بكامل طاقته دون اتصال بالإنترنت.

## كيفية الاستخدام

1.  **إدخال النص:** اكتب أو الصق النص العربي الذي ترغب في حمايته في مربع 
الإدخال.
2.  **اختيار طريقة المعالجة:** يمكنك اختيار محرف معين من القائمة المنسدلة، أو النقر على زر "تجربة أفضل طريقة تلقائيًا" للسماح للأداة باختيار الأنسب.
3.  **التحويل:** انقر على زر "تحويل الآن" لمعالجة النص.
4.  **النسخ والمشاركة:** بعد ظهور النص المحمي في مربع النتائج، يمكنك نسخه إلى الحافظة أو مشاركته مباشرة عبر تطبيقات التواصل الاجتماعي.
5.  **استعادة:** إذا أردت التراجع عن آخر تحويل، استخدم زر "استعادة السابق".

## التثبيت كتطبيق ويب تقدمي (PWA)

يمكنك تثبيت WordJoiner PRO كتطبيق على جهازك (هاتف ذكي أو كمبيوتر مكتبي) للوصول السريع والاستخدام دون اتصال بالإنترنت:

*   **على أجهزة Android (متصفح Chrome):**
    1.  افتح الموقع في متصفح Chrome.
    2.  انقر على أيقونة القائمة (ثلاث نقاط رأسية في الزاوية العلوية اليمنى).
    3.  اختر "إضافة إلى الشاشة الرئيسية" أو "تثبيت التطبيق".
    4.  اتبع التعليمات التي تظهر على الشاشة.
*   **على أجهزة iOS (متصفح Safari):**
    1.  افتح الموقع في متصفح Safari.
    2.  انقر على زر المشاركة (المربع الذي يحتوي على سهم يشير للأعلى).
    3.  مرر لأسفل وانقر على "إضافة إلى الشاشة الرئيسية".
    4.  انقر على "إضافة" في الزاوية العلوية اليمنى.
*   **على أجهزة الكمبيوتر المكتبية (متصفح Chrome/Edge):**
    1.  افتح الموقع في المتصفح.
    2.  ابحث عن أيقونة التثبيت في شريط العنوان (عادةً ما تكون أيقونة صغيرة تشبه الكمبيوتر مع سهم).
    3.  انقر عليها واتبع التعليمات لتثبيت التطبيق.

# WordJoiner PRO - Arabic Text Protector

![WordJoiner PRO Logo](icons/icon-192x192.png)

## Overview

**WordJoiner PRO - Arabic Text Protector** is an advanced web tool specifically designed to solve the Arabic word merging issue that occurs when copying and pasting text into popular social media applications like TikTok, WhatsApp, Telegram, Facebook, and YouTube. This tool ensures that your Arabic texts remain correctly formatted and readable without any unwanted changes to word structure.

## Key Features

*   **Modern & Responsive User Interface:** An attractive and easy-to-use design that works seamlessly across all devices, from smartphones to desktops.
*   **Full Arabic (RTL) Support:** An interface specifically designed to support right-to-left text direction, providing a natural user experience for Arabic speakers.
*   **Dark Mode:** An option to switch the interface to dark mode for a comfortable viewing experience in low-light conditions.
*   **Multiple Text Processing Options:**
    *   **Word Joiner (U+2060):** An invisible character that prevents word merging.
    *   **Zero Width Joiner (U+200D):** An invisible character that connects characters.
    *   **Zero Width Non-Joiner (U+200C):** An invisible character that prevents characters from connecting.
    *   **Hair Space (U+200A):** A very thin space.
    *   **Thin Space (U+2009):** A thin space.
    *   **Non-Breaking Space (U+00A0):** A non-breaking space.
*   **Automatic Best Method Trial:** A smart button that tries different joiners and selects the most effective method to ensure optimal text protection.
*   **Integrated Text Tools:** Input box, output box, buttons for convert, copy, share, clear, paste, and undo previous text.
*   **Religious Text Support:** An intelligent mechanism to preserve Quranic verses, diacritics, and pause marks without alteration, with a warning to the user when processing Quranic text.
*   **Text Statistics:** Displays word count, character count, and character count before and after conversion, as well as text size.
*   **Professional Progressive Web App (PWA):** Installable on the home screen and fully functional offline.

## How to Use

1.  **Enter Text:** Type or paste the Arabic text you wish to protect into the input box.
2.  **Choose Processing Method:** You can select a specific joiner from the dropdown list, or click the "Try Best Method Automatically" button to let the tool choose the most suitable one.
3.  **Convert:** Click the "Convert Now" button to process the text.
4.  **Copy & Share:** After the protected text appears in the results box, you can copy it to the clipboard or share it directly via social media applications.
5.  **Undo:** If you want to revert the last conversion, use the "Undo Previous" button.

## PWA Installation

You can install WordJoiner PRO as an application on your device (smartphone or desktop) for quick access and offline use:

*   **On Android Devices (Chrome Browser):**
    1.  Open the website in Chrome browser.
    2.  Tap the menu icon (three vertical dots in the top right corner).
    3.  Select "Add to Home screen" or "Install app".
    4.  Follow the on-screen prompts.
*   **On iOS Devices (Safari Browser):**
    1.  Open the website in Safari browser.
    2.  Tap the Share button (the square with an upward arrow).
    3.  Scroll down and tap "Add to Home Screen".
    4.  Tap "Add" in the top right corner.
*   **On Desktop Computers (Chrome/Edge Browser):**
    1.  Open the website in the browser.
    2.  Look for the install icon in the address bar (usually a small computer-like icon with an arrow).
    3.  Click on it and follow the instructions to install the application.
